# Buzzworthy

An answer-first quiz party game. The host's computer shows the board; everyone else joins from their phone by scanning a QR code, and their phone becomes a buzzer. Build your own boards and play them with friends.

- **Free to run:** a static site on GitHub Pages. Phones talk to the host's browser directly over WebRTC, with no game server.
- **Play:** https://wittywitters.github.io/buzzworthy/ (once the first version ships)

See [docs/DESIGN.md](docs/DESIGN.md) for how it works.
